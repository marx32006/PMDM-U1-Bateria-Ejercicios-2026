# Ej09 · Android, iOS y HarmonyOS con interfaces 🟣

**Apartado 3 · Sistemas operativos móviles** · ⏱️ 35 min

> 🎯 Repasar los **sistemas operativos móviles** y, de paso, practicar **interfaces** en Kotlin: tres clases distintas que cumplen el mismo «contrato».

