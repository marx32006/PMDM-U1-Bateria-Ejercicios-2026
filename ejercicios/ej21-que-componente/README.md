# Ej21 · ¿Qué componente uso? 🟣

**Apartado 5 · Componentes de una aplicación** · ⏱️ 25 min

> 🎯 Saber **qué componente** de una app Android usar en cada situación: Activity, Fragment/Composable, ViewModel, Repository, Service, BroadcastReceiver o ContentProvider.

## Pasos

**PASO 1.** Lee el `enum` `Componente` de [`Componentes.kt`](Componentes.kt): cada valor lleva su descripción.

**PASO 2.** En el mapa `respuestas`, **todos los casos tienen ahora `Componente.ACTIVITY`**. Cambia cada uno por el componente correcto. Hay **7 casos y 7 componentes**: cada componente se usa **una vez**.

**PASO 3.** Ejecuta:

```bash
./ejecutar.sh ejercicios/ej21-que-componente/Componentes.kt
```

## ✅ Comprueba

- Salen 7 líneas, una por caso, con el componente elegido y su descripción.
- La última línea dice `Componentes distintos usados: 7 de 7`. Si sale menos, has repetido alguno.
- Compara tus respuestas con tu compañero o compañera: ¿coincidís?
