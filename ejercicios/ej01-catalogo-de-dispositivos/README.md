# Ej01 · Catálogo de dispositivos 🟣

**Apartado 1 · Dispositivos móviles: tipos y características** · ⏱️ 30 min

> 🎯 Repasar los **tipos de dispositivos móviles** (smartphone, tablet, wearable, eBook, plegable, PDA) modelándolos en Kotlin con una **`data class`** y trabajando con listas: `filter`, `map`, `maxBy` y `groupBy`.

## Pasos

Completa [`Catalogo.kt`](Catalogo.kt) siguiendo los comentarios `// PASO`. Ejecútalo:

```bash
./ejecutar.sh ejercicios/ej01-catalogo-de-dispositivos/Catalogo.kt
```

Después contesta en [`RESPUESTAS.md`](RESPUESTAS.md).
