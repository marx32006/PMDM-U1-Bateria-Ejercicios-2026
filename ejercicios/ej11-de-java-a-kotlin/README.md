# Ej11 · De Java a Kotlin 🟣

**Apartado 3 · Kotlin y Java** · ⏱️ 40 min

> 🎯 Comprobar las ventajas de **Kotlin** frente a **Java** que da el tema: **menos código**, **sintaxis más limpia** y **más seguro** (seguridad frente a nulos). Vas a «traducir» una clase Java a Kotlin.

## Pasos

**PASO 1.** Lee [`Alumno.java`](Alumno.java). **No hay que ejecutarlo**: cuenta sus líneas.

**PASO 2.** Completa [`Alumno.kt`](Alumno.kt), que hace lo mismo en Kotlin, y ejecútalo:

```bash
./ejecutar.sh ejercicios/ej11-de-java-a-kotlin/Alumno.kt
```

**PASO 3.** Contesta en [`RESPUESTAS.md`](RESPUESTAS.md).
