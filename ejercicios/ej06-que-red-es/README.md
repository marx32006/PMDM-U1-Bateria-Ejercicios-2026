# Ej06 · ¿Qué red es? 🟣

**Apartado 1 · Redes y protocolos** · ⏱️ 25 min

> 🎯 Asociar cada **protocolo** con su **generación** y deducir la generación a partir de una **velocidad medida**, usando la expresión **`when`** de Kotlin.

| Generación | Protocolos |
|---|---|
| 1G | AMPS (EE. UU.), NMT (Escandinavia) |
| 2G | GSM (Europa), IS-136 (EE. UU.) |
| 2.5G | GPRS, EDGE |
| 3G | UMTS, CDMA |
| 3.5G | HSDPA |
| 4G | LTE, WiMax |
| 4G+ | LTE-A |

## Pasos

Completa [`Redes.kt`](Redes.kt) y ejecútalo:
